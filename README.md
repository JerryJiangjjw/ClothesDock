# 晾晾 · ClothesDock

Dock 采用透明背景，只显示从屏幕两端牵入的弧形晾衣绳、应用与固定文件夹；设置从菜单栏衣架进入。

采用晾衣绳设计的原生 macOS Dock 应用。Swift + AppKit + SwiftUI，无第三方依赖，macOS 14+。当前版本为可运行的功能初版，**尚未达到原生 Dock 全部功能等价**。参考项目：[Docky](https://github.com/josejuanqm/docky)、[DeskBar](https://github.com/rajeshgoli/deskbar)、[DockDoor](https://github.com/ejbills/DockDoor)。

## 构建与启动

```sh
./scripts/build.sh
open build/ClothesDock.app
```

Apple Silicon 默认生成本机架构；Intel 需要在 Intel 主机编译或另行交叉构建。当前签名为本地 ad-hoc，尚未公证，不是公开发行安装包。没有 Xcode 工程依赖，使用 Swift 6+ 的 Command Line Tools 与匹配的 SDK。

首次启动自动导入系统 Dock 的应用、文件夹与文件。系统 Dock 默认继续显示。点击菜单栏衣架 → 设置 → 开启替代模式，可隐藏普通桌面中的原 Dock；App Exposé、Mission Control 等系统界面仍可能强制显示原 Dock。退出晾晾或使用“恢复系统 Dock”恢复原设置。独立守护进程在异常退出后恢复；下次启动也检查残留备份。

将打包后的 .app 放到固定位置，再开启登录启动和授权，以免反复改变应用路径影响系统授权。

已按需求移除窗口管理、窗口预览及其授权入口；应用不再请求辅助功能或屏幕录制权限。

## 使用

- 点击图标启动/激活应用，圆点表示运行，蓝色表示前台。
- 拖动图标到另一个图标前方排序，非固定应用会同时固定；右键可移除固定项。
- 从 Finder 拖入应用/文件夹固定；把文档拖到应用图标交给该应用打开。
- 右键应用可隐藏、退出或在 Finder 中显示；文件夹菜单浏览最多 80 项。
- 极简 Dock 已移除右侧功能区（最小化窗口汇总、磁盘、设置按钮）；废纸篓以独立图标挂在末尾，点击打开、拖入文件回收、右键确认清倒。
- ⌃⌥D 显示/隐藏晾衣绳。快捷键冲突时使用菜单栏。
- 设置支持顶部/底部/左侧/右侧、多显示器、尺寸、边缘距离、自动隐藏、减少动态和登录启动。顶部避开菜单栏；左右位置的绳子从可用屏幕上下两端牵入。
- 绳子粗细可调为 0.5–6 px，颜色提供黑、白、灰、棕四种预设，默认灰色；衣夹采用一体式轮廓，下端覆盖图标边缘，像夹住衣物一样夹住应用。
- 自动隐藏的触发距离可调为 1–80 px，默认 12 px；只有鼠标进入所选物理屏幕边缘的触发范围才展开，移入应用区后保持显示。
- 衣夹沿绳子的弧度定位，应用绕衣夹摆动；悬停和点击触发绳子波动与邻近应用的衰减摆动。关闭动态或启用系统“减少动态效果”后，保留静态弧形；自动隐藏时暂停动画。绳子所在的装饰窗口不接收鼠标事件。

## 功能覆盖与缺口

| 原 Dock 能力 | 当前状态 |
| --- | --- |
| 启动应用、切换应用、运行指示 | 已实现 |
| 固定、移除、持久排序、导入原列表 | 已实现 |
| 最近应用 | 已实现本次运行期间最近退出的 5 个应用；不是系统最近应用数据库 |
| 文件/文件夹入口 | 已实现列表与打开；扇形/网格堆栈、春载文件夹尚未实现 |
| 文件交给应用 | 已实现 |
| 废纸篓 | 独立图标，支持打开、回收与确认清倒 |
| 推出卷 | 未提供 |
| 自动隐藏、位置、尺寸、放大、多屏 | 已实现；全屏、多屏、不同缩放仍需实机验收 |
| 登录启动 | 已实现 SMAppService；需固定路径下实机验收 |
| 原 Dock 隐藏/恢复 | 普通桌面的自动隐藏延迟 + 备份 + 进程守护；不保证 App Exposé / Mission Control 内隐藏 |
| Mission Control / Spaces / 系统 Cmd+Tab | 保留系统 Dock 进程，由 macOS 提供，不替换系统实现 |
| 第三方通知徽标、进度、动态 Dock Tile | 未实现；公开 NSDockTile 接口不能订阅所有应用 |
| 第三方应用自定义 Dock 菜单 | 未实现；本版本提供统一管理菜单 |
| App Exposé、分配到桌面、Handoff、弹跳请求 | 未实现完整等价 |
| Dock 键盘焦点/全局窗口切换器 | 未实现完整等价；仅保留显示/隐藏晾衣绳的快捷键 |
| 占用屏幕工作区（最大化避让） | 未实现；面板覆盖屏幕底部，建议开启自动隐藏 |

不禁用 SIP、不注入系统进程、不永久终止 Dock。原系统 Dock 进程仍承担 macOS 桌面/Spaces 等职责。

## 数据与恢复

配置：`~/Library/Application Support/ClothesDock/config.json`。
替代模式备份：同目录 `dock-backup.json`。只修改 `autohide`、`autohide-delay`、`autohide-time-modifier` 三个键；恢复原先不存在的键会删除该键，不改固定项或其他用户偏好。

如果守护进程与应用同时被强制结束，重新启动打包后的应用会恢复备份。避免同时运行多个不同路径/不同 bundle ID 的副本。

## 验证

```sh
./scripts/test.sh
```

配置测试覆盖双向排序、无效目标、路径去重、原子保存/读取和损坏文件回退。布局与动态测试覆盖四边位置、屏幕边缘、顶部菜单栏避让、曲线端点和减少动态；升级测试覆盖旧配置保留固定项及新设置持久化。守护进程测试使用模拟 defaults/killall，验证退出恢复和错误时保留备份，不改系统 Dock。

窗口管理、窗口预览和“所有应用”启动器已移除。多屏、全屏、登录启动及 Finder 自动化仍需按实际环境验收。

悬停区域缩小到图标原始尺寸的固定矩形，排除衣夹、绳子和槽位空白，图标旋转和放大不改变悬停边界；短时间穿过相邻槽位会继续当前波动，避免反复重置导致抖动。

应用图标源文件为 `Resources/AppIcon.png`，macOS 图标为 `Resources/AppIcon.icns`，构建时自动嵌入。修改源图后运行 `./scripts/build-icon.sh` 重新生成多尺寸图标。生成方式与提示词见 `Resources/icon-design.md`。
